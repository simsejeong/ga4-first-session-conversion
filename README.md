## 1. 문제 정의

> **가상 PM 요청**
> "신규 사용자가 지속적으로 유입되고 있지만, 첫 방문 이후 실제 구매와 재방문으로 이어지는 비율이 기대에 미치지 못하고 있습니다.
> 신규 사용자의 초기 행동 중 구매 전환과 재방문에 연결되는 핵심 행동을 찾아, 제한된 개발 리소스에서 우선적으로 개선해야 할 영역을 제안해 주세요."

- **목표 지표(Y)**: 신규 고객 매출 = 신규 사용자 수 × **구매전환율** × 구매자당 평균 매출
- 신규 유입은 지속된다고 가정하고, 구매금액 확대보다 **미구매자의 전환 유도**를 우선 → 구매전환율을 개선 지표로, 재방문을 보조 성과로 설정

## 2. 데이터와 운영 정의

| 항목 | 정의 |
|---|---|
| 데이터 | Google Merchandise Store GA4 공개 샘플 (2020.11.01 ~ 2021.01.31, 92일) |
| 신규 사용자 | 최초 관찰 이벤트 시각 = 최초 `first_visit` 시각인 사용자 **256,914명** |
| 첫 세션 | 신규 사용자의 최초 `first_visit`에 연결된 `ga_session_id` |
| D7 구매 | 첫 방문 후 168시간 이내 유효 구매 (주문번호 2개 필드 통합, 식별 불가 23건 제외) |
| D1~D7 재방문 | 첫 세션 시작 후 24~168시간 사이 새로운 세션 발생 |
| 관찰 가능 | 데이터 종료 시점까지 168시간 관찰이 확보된 사용자 **238,279명** (우측 절단 보정) |

**데이터 품질 검증에서 발견한 것**
- `first_visit` 중복 기록 147명 → 사용자 수는 `DISTINCT user_pseudo_id`로 집계
- `ga_session_number = 1`만으로 정의하면 최초 접촉 정보가 없는 3,834명이 섞임 → `first_visit` 기준 채택
- `ga_session_id`가 사용자 간 재사용됨(최대 17명) → 세션 키는 `user_pseudo_id + ga_session_id`
- 정수 시간 절삭(`TIMESTAMP_DIFF ... HOUR`)으로 168시간을 넘긴 구매 7명이 섞임 → 실제 timestamp 경계로 비교

| 기준 지표 | 값 |
|---|---:|
| D7 구매전환율 (관찰 가능 신규 사용자) | **1.16%** (2,754명) |
| D1~D7 재방문율 | **5.10%** (12,164명) |
| 첫 세션 미구매자의 이후 D7 구매전환율 | **0.47%** (236,648명 중 1,122명) |

## 3. 분석 흐름 — 행동 X를 세 번 재정의한 과정

| 단계 | 행동 X 후보 | 근거 |
|---|---|---|
| ① 행동 분석 | 검색 후 상품 조회 3회 이상 | 전환율 격차 +2.44%p, 구매자 포괄률 61.68% |
| ② 모델 검증 | 첫 세션 상품 조회 1회 이상 | 비검색 상품 조회 0회 → 1회 구간의 평균 SHAP 증가폭 최대(+0.88) |
| ③ 데이터 재검증 | **탐색 경유 상세 도달** | `view_item`의 60.42%가 목록 페이지에서 발생 → 페이지 유형으로 상세 도달을 재정의 |

- 단일 이벤트로 전환율이 가장 높은 행동(결제 직전 행동)은 이미 구매 의도가 높은 사용자의 행동이라 개선 레버에서 제외
- 다변량 모델(LightGBM)에서 `검색 후 상품 조회`의 중요도는 11위(0.004)로 낮아, 단변량 분석 결과만으로 X를 확정하지 않음
- 프로모션 노출은 SHAP 1위지만 메인 페이지 방문과 밀접해 진입 경로(통제 변수)로 분류

## 4. 핵심 결과

**모델 성능** (첫 세션 미구매자 · 이후 D7 구매, 테스트셋)

| 지표 | Logistic | **LightGBM** |
|---|---:|---:|
| PR-AUC (기준선 0.0047) | 0.0625 | **0.0684** |
| ROC-AUC | 0.8665 | **0.8726** |
| 상위 10% Lift | 6.16배 | **6.79배** |
| 상위 10% Capture | 61.6% | **67.9%** |

**탐색 단계별 성과** (첫 세션 미구매 신규 사용자 236,648명)

| 탐색 단계 | 사용자 비중 | D7 구매전환율 | 구매자 포괄률 |
|---|---:|---:|---:|
| 상품 탐색 화면 미도달 | 30.94% | 0.09% | 6.06% |
| 목록·검색까지만 도달 | 47.69% | 0.41% | 41.00% |
| 상세 직접 랜딩 | 13.40% | 0.26% | 7.22% |
| **탐색 경유 상세 도달** | **7.97%** | **2.72%** | **45.72%** |

→ 전체의 8.0%인 탐색 경유 상세 도달자가 D7 구매자의 45.7%를 차지

**개선 기회 — 목록 페이지**
- 카테고리·목록은 방문율이 가장 높지만(56.0%) **상세 직행률은 9.7%**
- 목록 페이지뷰의 **79.7%가 다른 목록으로 이동하거나 이탈**
- → **목록 상품 카드 개선**을 우선 검증 대상으로 선정 (메인 화면 탐색 개선은 후속 과제)

**A/B 테스트 설계** — 목록 상품 카드 UI 개선 (상품 정보 가독성 개선 · 상품 보기 버튼 추가)

- 대상: 실험 기간 중 최초 방문 신규 사용자, 사용자 단위 50:50 무작위 배정
- 우선 적용: 방문량 상위 3개 목록 (목록 페이지뷰의 39.5%)
- 1차 지표: 실험 대상 목록 방문자의 상세 도달률 / 유의수준 5%, 검정력 80%

**기대 비즈니스 효과** (첫 세션 미구매자 기준 시뮬레이션)

## 7. 한계와 개선 방향

- 공개 샘플(난독화) 데이터로, 실제 기업의 개선 효과를 입증한 것은 아님
- 첫 세션 행동과 구매의 관계는 연관성이며 인과관계가 아님 → A/B 테스트로 검증 필요
- 모델은 무작위 분할로 평가 → 시간 순서 기반(미래 기간) 검증 필요
- 기대 효과는 가정 기반 시뮬레이션이며 개발·운영 비용은 반영하지 않음
